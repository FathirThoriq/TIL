# Pindah dari Arch ke Fedora

*2026-10-13 · linux*

Laptopku pindah dari Arch Linux ke Fedora. Yang paling terasa di minggu pertama:

- Manajer paket: `pacman -Syu` → `sudo dnf upgrade`; `pacman -S <paket>` → `sudo dnf install <paket>`; cari paket: `dnf search`. Otot lama masih sering mengetik pacman.
- Shell defaultku dulu fish di Arch; di Fedora mulai dari bash dulu supaya petunjuk instalasi dari internet tidak perlu diterjemahkan.
- Kebiasaan rolling-release harus dilonggarkan: Fedora rilis per versi (±6 bulan), jadi "selalu paling baru" bukan lagi default — dan itu tidak apa-apa buat mesin kerja.

Catatan ini kutulis supaya lain kali ada yang menanyaiku perintah terminal, konteksnya jelas: **Fedora + dnf**, bukan Arch lagi.
